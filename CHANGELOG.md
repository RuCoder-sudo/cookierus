# Changelog для CookieRus

Все значимые изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.3] - 2026-09-05

### Added
- Добавлена адаптивная широкая компоновка модального окна «Настроить» с удобными вкладками и сеткой категорий и целей.
- На вкладке «Информация» оставлена подпись «Разработчик плагина CookieRus» без персональных данных.

### Fixed
- Исправлена вложенность карточек на странице настроек: разделы «Модальное окно», «Трекеры» и «Цели» больше не объединяются в один блок.
- Обновлены служебные подписи и отображение версии плагина до 1.1.3.

## [1.1.2] - 2026-09-05

### Added
- Добавлена строгая блокировка аналитики и маркетинговых трекеров до согласия: защищены статические и динамические скрипты, изображения, iframe, fetch, XMLHttpRequest, sendBeacon и Callibri-виджет.
- Добавлены пользовательские категории согласия с названием, описанием, ссылкой на политику и отдельным переключателем.
- Добавлены пользовательские цели обработки с настраиваемым заголовком, описанием и включением/выключением.
- Добавлено поле для вставки кода Callibri: он исполняется только после согласия на аналитические cookie и включения сервиса.
- Добавлены цели обработки «Ретаргетинг», «Создание профиля пользователя» и «Передача данных третьим лицам».
- Добавлены настраиваемый срок хранения функциональных cookie, ссылки на политики сервисов, кнопка отзыва согласия и удаление логов старше одного года.
- Добавлена настройка полного запрета авторизации через иностранные OAuth/social-login сервисы.
- Добавлена миграция новых настроек для существующих установок без сброса выбора администратора.

### Fixed
- Исправлен запуск отложенных inline-скриптов после согласия: теперь создаётся новый исполняемый элемент `script`.
- Усилена блокировка Callibri и трекинговых запросов, которые создаются через DOM и сетевые API.
- Исправлена защита иностранных OAuth-кнопок и маршрутов в AJAX, в шапке сайта и при динамической загрузке.
- Названия сервисов и текущая версия 1.1.2 выровнены в админке, баннере и документации.

## [1.1.1] - 2026-08-31

### Fixed
- Исправлена критическая ошибка регистрации: `WP_Error::get_error()` заменён на штатный метод `WP_Error::get_error_codes()`, доступный в поддерживаемых версиях WordPress.

## [1.1.0] - 2026-08-27

### Changed
- Полностью удалены сторонний менеджер тегов и связанные с ним настройки и загрузка скриптов.
- В окно «Настройки согласия» добавлена вкладка «Упоминания» с правилами регистрации и входа для сайта, WooCommerce и `/wp-admin/`.
- Единая проверка российских почтовых доменов применяется к регистрации, входу, изменению email и восстановлению доступа.
- Устаревшие настройки трекеров автоматически очищаются при сохранении настроек.
- Юридические формулировки в справке уточнены: плагин не обещает автоматическое соответствие всем требованиям без проверки фактической обработки данных.

## [1.0.8] - 2026-08-02

### Fixed
- **Технические ответы WordPress** — CookieRus больше не добавляет HTML-баннер в `robots.txt`, sitemap, RSS/Atom, REST API и XML-RPC.
- **Безопасная вставка баннера** — если в ответе отсутствует закрывающий тег `</body>`, исходный ответ возвращается без изменений вместо добавления HTML в конец.

### Changed
- Перед запуском буферизации добавлена проверка технических запросов, включая стандартные WordPress-признаки и sitemap-варианты.
- Версия плагина обновлена до 1.0.8 во всех файлах.

## [1.0.7] - 2026-06-02

### Fixed
- **Кнопки баннера в ряд** — устранена ключевая ошибка: inline-стиль `max-width: 460px !important` с ID-селектором (#cookierus-banner) перебивал CSS-класс `.cr-btns-row { max-width: 600px }` из-за более высокой специфичности. Теперь max-width задаётся динамически: 640px в режиме «В ряд», 460px в режиме «Колонкой».
- **Надёжность режима «В ряд»** — CSS-правила для `.cr-btns-row` переведены на селектор `#cookierus-banner.cr-btns-row` (ID + класс), что гарантирует `flex-direction: row` и `flex-wrap: nowrap` даже на сайтах с агрессивными стилями темы.
- **Кнопка «Свернуть»** — полный сброс стилей темы: добавлены `background-color`, `background-image`, `-webkit-appearance`, `appearance`, явные `width`/`height: auto`, `min-height: 0`, `text-decoration: none`. Кнопка всегда отображается как маленький текст + иконка, а не как полноразмерная кнопка.
- **Отступы на мобильных** — медиа-запрос `480px` больше не переводит кнопки в колонку в режиме «В ряд»; на экранах < 380px колонка разрешена, более широкие экраны сохраняют ряд.

### Changed
- Версия плагина обновлена до 1.0.7 во всех файлах.

## [1.0.5] - 2026-05-29

### Added
- **Иконка cookie в баннере** — настройка отображения иконки cookie перед текстом баннера с выбором размера (маленький / средний / большой).
- **Дополнительная кнопка в баннере** — настройка произвольной кнопки с кастомным текстом, URL, цветом фона и текста.
- **Расширенные настройки стилизации** — закругление кнопок (0–20 px), размер шрифта кнопок (12–18 px), цвет ссылки политики, выбор шрифта (inherit / sans-serif / serif / mono), тень баннера (нет / лёгкая / средняя / тёмная), эффект при наведении (нет / осветление / затемнение / масштаб).
- **Режим сворачивания баннера** — тумблер «Разрешить сворачивать баннер». При нажатии кнопки закрытия баннер сворачивается в круглую плавающую иконку cookie в углу экрана. Повторный клик — баннер возвращается.
- **Настройка повторного показа** — опция определяющая, когда баннер показывать снова: никогда / через 7 дней / через 30 дней / при каждом посещении.
- **Автообновление через GitHub** — плагин проверяет обновления из репозитория https://github.com/RuCoder-sudo/cookierus напрямую через WordPress.
- **Значок версии в шапке админки** — бейдж `v1.0.5` отображается рядом с заголовком страницы настроек.

### Changed
- Версия плагина обновлена до 1.0.5 во всех файлах.
- Plugin URI обновлён до https://github.com/RuCoder-sudo/cookierus.
- Tested up to: WordPress 6.7.

### Fixed
- Мерцание баннера при переходах между страницами устранено: PHP-проверка куки до рендера + CSS `display:none` по умолчанию.
- Кнопка «Очистить все логи» теперь корректно защищена nonce.
